# 04: Filters and search

**What to build:** A visitor narrows everything on the page by release type, service, enhancement facet and a search term. The annual table, monthly chart and totals all recalculate. Search covers titles and reasons, and the page says so.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Filter choices are derived from the public dataset
- [ ] A multi-service announcement matches each of its services; a multi-facet announcement matches each of its facets
- [ ] Search is a case-insensitive substring match over title and reason
- [ ] A visible note states that announcement bodies are not searched
- [ ] Filters combine, and can be cleared
- [ ] The Node check matches the released per-service matched comparison file
- [ ] The Node check matches the local explorer's summary results for a small fixed set of type, service and facet filters
