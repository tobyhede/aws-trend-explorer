# 03: Monthly chart with counts and shares

**What to build:** A visitor sees a monthly stacked chart of announcements by magnitude level from January 2021 to the collection cutoff, can switch it between counts and shares, and can read the same numbers in a table.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] The chart shows every month in the release, with the partial final month marked
- [ ] The share view divides each level's count by all filtered announcements, including needs-review and outside-scale
- [ ] A legend names every level, using the names in the data guide
- [ ] A table gives the monthly values for readers who cannot use the chart
- [ ] Chart marks are reachable and labelled for keyboard and screen-reader use
- [ ] The Node check matches the released monthly aggregate file exactly
