# 05: Record list, drill-down and export

**What to build:** A visitor selects a bar in the monthly chart or a cell in the annual table and sees the records behind that count. Each record shows its date, title, services, magnitude level and reason, and links to the official AWS announcement. The visitor can page through the list and export the filtered records as CSV.

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] Selecting a monthly bar lists the records for that month and level
- [ ] Selecting an annual cell lists the records for that year's matched period and level
- [ ] The number of records listed equals the count that was selected
- [ ] Active filters and search apply to the list
- [ ] Records are ordered by date, newest first, and paged
- [ ] Every record links to its source URL
- [ ] CSV export contains the filtered records with the nine public fields
- [ ] Drill-down works by keyboard
