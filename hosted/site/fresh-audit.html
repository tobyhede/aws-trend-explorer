Fresh classification accuracy audit

24 November 2026 · 2025–28 October 2026 source window

173/200 (86.5%) frozen production classifications match the blind adjudicated AI reference. Wilson 95% interval: 81.1%–90.6%.

Sampling frame: 4,578 previously un-audited records; 342 previously audited records excluded. Two readers independently classified all 200 without production labels. A third reader assessed all disagreements/low-confidence cases and 20 randomly selected agreements. The reference was frozen before scoring.

Initial reader agreement: 191/200 (95.5%). Third-reader source checks: 31. Uncertain reference labels: 4. Production labels remain unchanged.

For records the reference identifies as product changes (levels 1–5), exact agreement is 112/135 (83.0%). This excludes easy outside-scale cases, but is a conditional estimate.

Reference-uncertainty sensitivity: if all 4 uncertain reference cases were incorrect versus correct in production, the score would range from 86.0% to 88.0%. This is not a confidence interval.

  • Estimate applies to 4,578 previously un-audited records, not automatically to all 4,920 classified records.
  • Prior audits removed most or all existing level-4/5 records; this sample cannot validate those category precisions.
  • Independent AI readers can share systematic errors. Accuracy here means agreement with an adjudicated AI reference.
  • Wilson intervals describe sampling uncertainty only, not uncertainty in the reference judgments.
  • Saved announcement text was used; no fresh AWS retrieval or coverage audit was performed.
  • Production classifications were frozen before sampling review and have not been corrected as part of this accuracy measurement.
