Read the public dataset

Release: 27 November 2026. The public dataset is one Parquet file, aws-announcements-2026-11-27.parquet. It holds 22,588 records, one for each collected AWS announcement from 1 January 2010 to 28 October 2026. The hosted explorer reads this same file.

The file does not contain the text of any announcement. Follow a record's source_url to read the announcement on the AWS website.

Fields

The file has nine fields. source_url identifies a record in this release.

FieldTypeMeaning
announcement_dateDatePublication date.
titleTextAnnouncement title, as AWS published it.
serviceTextService tags separated by ; (semicolon and space). unknown means no service tag is available.
release_typeTextRelease-type label retained from an earlier classification.
enhancement_facetsTextEnhancement labels retained from an earlier classification, separated by |. Empty when the announcement has none.
product_change_levelTextMagnitude level, defined below. It is text, not a number: the values are 1 to 5, U and NA.
product_change_reasonTextOur explanation of the level, written from the announcement and the recorded review.
product_change_basisTextProvenance: which reading or adjudication produced the level.
source_urlTextAddress of the official AWS announcement.

U and NA are explicit decisions, not missing values. The file also records the release date and the collection cutoff in its metadata, under the keys release_date and collection_cutoff.

Magnitude levels

The scale describes the announced product change, not its consequences for a customer.

CodeLevelDecision rule
1Parameter changeA limit, default, performance characteristic, or supported catalogue value changes.
2Capability refinementControls, options, compatibility, or targets extend an existing operation.
3New capabilityA distinct new operation or interface appears within an existing product.
4Major product expansionA substantial subsystem or new execution, operating, or programming model appears.
5New productAWS positions a distinct offering that customers can adopt. Billing is supporting evidence.
UNeeds reviewThe evidence does not establish the change sufficiently.
NAOutside scalePure geographic, price-only, compliance, educational, or lifecycle announcements.

Mixed announcements receive the highest substantive level supported by their text. Routine hardware, runtime, and model catalogue additions are generally level 1. An additional integration target is generally level 2. A first integration that adds a distinct capability can be level 3.

General availability alone does not imply a new product. Billing functionality is assessed on the scale even though pure price changes are outside it.

The levels are ordered categories, not arithmetic weights. Do not multiply counts by the level number to estimate effort or value. The method page gives the full rubric and reviewed examples.

Periods and totals

  • Matched period. Year comparisons count 1 January to 28 October in every year, because the final year stops at the collection cutoff.
  • Months. The monthly chart uses whole calendar months. The final month ends on 28 October.
  • In-scale totals include U and exclude NA.
  • Shares divide each level's count by all filtered announcements, including U and NA.
  • Year-on-year change compares adjacent matched periods, using the previous year's in-scale total as the denominator.
  • Service tags overlap. Count a multi-service announcement once for each of its services, but once in the whole collection. Do not add service totals together.

Query the file yourself

Any tool that reads Parquet keeps the column types. For example, in DuckDB:

select year(announcement_date) as year, product_change_level as level, count(*) as announcements
from 'aws-announcements-2026-11-27.parquet'
where strftime(announcement_date, '%m-%d') <= '10-28'
group by all order by all;

That query gives the hosted explorer's matched-period table. To count by service, split the tags first: unnest(string_split(service, '; ')).

Cite a release

The file name carries the release date. Each release keeps its own file at its own address, so a citation of aws-announcements-2026-11-27.parquet keeps pointing at the same data after later releases.

Interpret trends with the audits

Announcement volume measures publication activity. Preview, general availability and regional rollout can each produce a separate announcement of the same feature. Seasonal publication patterns and partial periods also affect apparent velocity. Unknown service tags and differences in collection coverage can affect service comparisons.

All levels are AI judgments. The historical audit and the fresh-sample audit report how often they agree with independent AI references, and the release notes list the limits that remain. Trends in levels 4 and 5 are provisional.
